# Skylang for Visual Studio Code

Official Visual Studio Code extension for the **Skylang** programming language.

## Features

- **Automatic Language Detection**: Detects `.sky` files automatically as Skylang.
- **Syntax Highlighting**: Full TextMate grammar support for keywords, types, control flow, functions, classes, gateways (`takes`), standard library modules, FFI, operators, and literals.
- **Intelligent Bracket & Auto-Closing**: Automatic closing and pairing of brackets `{}`, `[]`, `()`, `<>`, quotes `""`, and comments `/* */`.
- **Code Snippets**: Rich snippets for functions, classes, constructors, loops, Go-style error handling, and multi-language interop (Python, JS, C FFI).
- **Comment Toggling**: Supports `//`, `#`, and `/* ... */` comment toggling (`Ctrl+/` or `Cmd+/`).

## Getting Started

1. Open any `.sky` file.
2. Notice the syntax highlighting and language identifier `Skylang` in the status bar.
3. Use shortcuts and snippets like `f`, `class`, `takes`, `forin`, `errhandle`, `println`.
